# 1.4.1 — 인증서 수정 · 해결 버튼 · 도메인 연동

GitHub Releases에서 배포 파일을 받아 실행합니다. (빌드된 exe/zip이 있을 경우)

## 실행

1. 관리자 권한으로 `run.bat` 또는 배포 exe를 실행합니다.
2. **사용자 정보**에 VPN 접속 도메인을 입력·저장합니다.
3. **이슈별 조치**에서 증상을 선택해 점검합니다.

## 이번 버전

- Sectigo 인증서를 **컴퓨터 + 현재 사용자** 저장소에서 확인합니다.
- 중간 인증서만 있고 루트(R46)가 없으면 원인을 구체적으로 표시합니다.
- 문제가 나오면 **인증서 설치 / VPN 다시 실행 / 설치 파일 실행**으로 바로 해결할 수 있습니다.
- 관리자 확인이 필요한 항목은 결과 저장 후 담당자에게 문의하도록 안내합니다.
- 사용자 정보에 입력한 **VPN 도메인**으로 DNS·HTTPS를 점검합니다.
- 이슈 메뉴 8개를 가이드 기준으로 다시 나눴습니다. (`초기화 중` = 연결 이후 터널 초기화)
